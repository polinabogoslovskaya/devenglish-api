# Обоснование выбора темы

## Тема

**DevEnglish API — английский для разработчиков ПО.** Сервис помогает практиковать типичные фразы для code review, ежедневных встреч, описания ошибок, технической документации и Git.

## Сопоставление с таблицей занятых проектов

В доступной таблице есть проект LUX для изучения латинской лексики и Russian Verb Trainer для спряжения русских глаголов. DevEnglish отличается языком, целевой аудиторией и контекстом: английский используется в рабочем процессе разработки ПО, а данные организованы по инженерным ситуациям и уровням сложности.

Тема не является одним из перечисленных в требованиях типовых примеров (список задач, каталог книг, учёт расходов, заметки, заявки в поддержку, события, IoT-показания или задания обработки изображений). Это обоснование основано на доступной выгрузке списка занятых тем; окончательно уникальность может подтвердить только преподаватель.

## Собственная логика

- Поиск и фильтрация по категории, уровню и тексту фразы.
- Валидация вариантов ответа и проверка дублирующихся фраз.
- Викторина с проверкой ответа, объяснением и статистикой точности.
- Переменные окружения и структурированные логи.
- Автоматические тесты и GitHub Actions.
