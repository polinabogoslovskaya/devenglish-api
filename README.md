# DevEnglish API — английский для разработчиков

DevEnglish API — учебный REST-сервис для практики английского языка в типичных ситуациях разработки ПО: code review, daily meetings, описание багов, документация и Git. Карточки содержат английскую фразу, перевод, пример и уровень сложности; мини-викторина проверяет перевод и ведёт простую статистику.

## Возможности

- `GET /health` и `GET /version` для проверки сервиса.
- `GET /phrases` — просмотр карточек, фильтры `category` и `level`, поиск `q`.
- `GET /categories` — список тематических разделов и число карточек в каждом.
- `GET /phrases/{phrase_id}` — одна карточка.
- `POST /phrases` — добавить фразу вместе с четырьмя вариантами ответа.
- `GET /quiz/question` — получить вопрос викторины, необязательно отфильтровать по категории, уровню или ID.
- `POST /quiz/answer` — проверить ответ и получить объяснение.
- `GET /stats` — число попыток и точность ответов.
- Переменные окружения, логирование HTTP-запросов, pytest и GitHub Actions.

## Требования

Python 3.11+.

## Установка и запуск

```bash
python -m venv .venv
```

Активация окружения:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Зависимости и запуск с авто-перезагрузкой для разработки:

```bash
python -m pip install -r requirements-dev.txt
python -m uvicorn app_final:app --reload
```

Документация API: <http://127.0.0.1:8000/docs>

Обычный запуск без авто-перезагрузки:

```bash
python -m uvicorn app_final:app --host 0.0.0.0 --port 8000
```

## Примеры запросов

Список фраз:
```bash
curl http://127.0.0.1:8000/phrases
```

Фразы для code review среднего уровня:
```bash
curl "http://127.0.0.1:8000/phrases?category=code_review&level=intermediate"
```

Поиск по переводу или английскому тексту:
```bash
curl "http://127.0.0.1:8000/phrases?q=breaking"
```

Получить вопрос по конкретной карточке:
```bash
curl "http://127.0.0.1:8000/quiz/question?phrase_id=de-001"
```

Отправить ответ:
```bash
curl -X POST http://127.0.0.1:8000/quiz/answer \
  -H "Content-Type: application/json" \
  -d '{"phrase_id":"de-001","answer":"Можешь посмотреть это?"}'
```

Статистика:
```bash
curl http://127.0.0.1:8000/stats
```

## Категории и уровни

Категории: `code_review`, `meetings`, `bugs`, `documentation`, `git`. Уровни: `beginner`, `intermediate`, `advanced`. Это учебная маркировка сложности, а не официальный экзаменационный стандарт.

## Переменные окружения

| Имя | По умолчанию | Назначение |
|---|---|---|
| `APP_NAME` | `DevEnglish API` | Имя сервиса |
| `APP_VERSION` | `1.0.0` | Версия приложения |
| `APP_ENV` | `development` | Название окружения |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

`.env.example` показывает допустимый формат настроек. FastAPI сам по себе не загружает `.env`; задайте переменные в оболочке или подключите отдельный загрузчик. Файл `.env` не следует добавлять в Git.

## Тесты

```bash
python -m pytest -v
```

Тесты проверяют health/version, фильтрацию и поиск, защиту от дубликатов, викторину, неверный ответ, валидацию и статистику.

## Диагностика

- `ModuleNotFoundError`: активируйте виртуальное окружение и установите `requirements-dev.txt`.
- Порт занят: добавьте `--port 8001` в команду Uvicorn.
- `422 Unprocessable Entity`: проверьте обязательные поля и ограничения запроса.
- `404`: проверьте ID и фильтры; `409`: фраза с таким текстом уже существует.
- Если статистика сбрасывается после перезапуска, это ожидаемо: в прототипе используется хранилище в памяти процесса.

## Ограничения

Это учебный прототип без аккаунтов, базы данных, аудио-произношения и автоматической оценки свободного текста. Проверка ответа сравнивает введённый перевод с эталоном без учёта регистра и пробелов по краям. Для реального многопользовательского сервиса нужно добавить БД, авторизацию и изоляцию прогресса пользователей.

## CI

`.github/workflows/ci.yml` запускает тесты при `push` и `pull_request` и при успехе загружает артефакт через `actions/upload-artifact@v4`.
